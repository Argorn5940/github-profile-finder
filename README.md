# GitHub Profile Finder

GitHubのユーザー名を入力すると、GitHub REST APIからプロフィール情報を取得してターミナルに表示するCLIアプリです。

表示する情報:

- GitHubユーザー名
- 名前、自己紹介（未設定の場合は「未設定」）
- 公開リポジトリ数、フォロワー数、フォロー数
- プロフィールURL

## 使用技術・動作確認環境

- Node.js 24.22.1（動作確認済み）
- JavaScript（CommonJS）
- axios
- GitHub REST API

## インストール

プロジェクトのディレクトリで依存パッケージをインストールします。

```bash
npm install
```

## 起動方法

```bash
node app.js
```

表示されたプロンプトにGitHubのユーザー名を入力してください。前後の空白は自動で取り除かれます。

```text
GitHubのユーザー名を入力してください：octocat
ユーザー名: octocat
名前: The Octocat
自己紹介: 未設定
公開リポジトリ数: 8
フォロワー数: 24955
フォロー数: 9
プロフィールURL: https://github.com/octocat
```

※表示例のプロフィール情報や数値は変わることがあります。

## APIの利用制限と認証

初期版では認証なしでGitHub REST APIを利用します。認証されていないリクエストには、通常、送信元IPアドレスごとの利用制限（目安として1時間あたり60リクエスト）があります。制限に達した場合は時間をおいて再試行してください。利用制限はGitHubのポリシーや利用状況によって変更される場合があります。

APIリクエストには10秒のタイムアウトを設定しています。アクセス制限（403・429）やタイムアウトが発生した場合は、状況に応じたメッセージを表示します。

## 工夫した点・学んだこと

- 入力値を `trim()` で整え、空欄の場合はAPIを呼び出さないようにしました。
- URLに含めるユーザー名を `encodeURIComponent()` でエンコードしています。
- API取得、エラー表示、プロフィール表示を関数に分けました。
- axiosのタイムアウト設定と、403・429・タイムアウト時のエラー処理を追加しました。
- axiosをモックしてAPI通信を模擬し、ユーザー名のエンコードやエラー処理をテストできるようにしました。
